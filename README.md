# Python Asyncio Practice

Notes, runnable examples and exercises from learning Python `asyncio` (Python 3.11+).

## Structure
- `notes/`: revision notes with interview Q&A
- `examples/`: 5 runnable scripts (coroutines, sequential await, `create_task`, `gather`, `TaskGroup`)
- `exercises/`: 5 practice problems (starter code with TODOs)
- `PROGRESS.md`: learning log and checklist

## Run
```bash
python --version        # needs 3.11+
python examples/03_create_task.py
```
